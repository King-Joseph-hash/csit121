Image srcset Element

src="fallback.jpg"
This is the default image that the browser will load if srcset is not supported. If none of the images in srcset meet the conditions, this image is used.

All modern browsers support srcset.
srcset="large.jpg 1200w, medium.jpg 800w, small.jpg 500w"
multiple image files with different widths (w stands for width in pixels)
The browser will choose the most appropriate image based on the screen size and resolution.

Example:
  • large.jpg 1200w → for screens that need an image width of 1200 pixels.
  • medium.jpg 800w → for screens that need an image width of 800 pixels.
  • small.jpg 500w → for screens that need an image width of 500 pixels.
sizes="100vw"
Defines how much viewport width (vw) the image should take up. 100vw means the image should always be as wide as the viewport (full width). This helps the browser determine which image from srcset to use.
