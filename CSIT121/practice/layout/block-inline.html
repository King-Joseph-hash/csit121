Paragraph tags are block-level elements. Block-level elements leave a blank line above and below and its 'area' extends to its parent's margins.

In this case, the parent is <body> and there are no explicit margins defined, so it defaults to the full width of the viewport. Try adding and changing the margin property.

This block of text's parent is <div>.

Anchor tags are inline elements - they appear on the same line when there is sufficient room.

The configured border makes it easy to see how much space each anchor tag uses.
