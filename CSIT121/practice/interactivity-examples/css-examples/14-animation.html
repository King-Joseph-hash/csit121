Animation Demo: animation: bounce 2s ease-in-out 0.5s infinite alternate;

Element

The Animation Code:

.element {
    animation: bounce 2s ease-in-out 0.5s infinite alternate;
}

@keyframes bounce {
    0% {
        transform: translateY(0);
    }
    100% {
        transform: translateY(-100px);
    }
}

Breaking Down the Animation Shorthand:

Property Value Explanation
animation-name bounce The name of the keyframe animation defined with @keyframes
animation-duration 2s The animation takes 2 seconds to complete one cycle
animation-timing-function ease-in-out Animation starts slowly, speeds up in the middle, then slows down at the end
animation-delay 0.5s Animation waits 0.5 seconds before starting
animation-iteration-count infinite Animation repeats forever
animation-direction alternate Animation plays forward then backward, creating a bouncing effect

About the Bounce Animation:

This animation moves the element up 100px from its original position and then back down due to the "alternate" direction property. The "ease-in-out" timing function makes the movement appear more natural, like a bounce with gradual acceleration and deceleration.

The "alternate" direction makes the animation play forwards then backwards, creating a continuous bouncing effect, while "infinite" ensures it keeps repeating.
