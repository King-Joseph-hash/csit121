CSS Animation Exercises

Complete the following exercises to practice using CSS animations and transitions. Each exercise includes the objective, starter code, and hints to help you complete the task.

Exercise 1: Button Hover Effect

Objective: Create a button that changes color and size when hovered.

Modify the CSS for the button below to add a smooth transition effect when hovered. The button should change its background color and increase slightly in size.

Hints:
  • Use the transition property on the button
  • Apply transform: scale() for size change
  • Remember to specify which properties to transition and the duration
/* CSS */ .ex1-button { background-color: #3498db; color: white; border: none; padding: 12px 24px; font-size: 16px; border-radius: 4px; cursor: pointer; /* Add transition */ transition: background-color 0.3s ease, transform 0.2s ease; } .ex1-button:hover { background-color: #2980b9; transform: scale(1.05); }

Exercise 2: Loading Spinner

Objective: Create a continuously rotating loading spinner.

Add CSS to make the circle below rotate continuously, creating a loading spinner effect.

Hints:
  • Use @keyframes to define the rotation
  • Apply animation to make it spin continuously
  • Consider using linear timing for a constant speed
/* CSS */ .ex2-loader { width: 50px; height: 50px; border: 5px solid #f3f3f3; border-top: 5px solid #3498db; border-radius: 50%; animation: spin 1s linear infinite; } @keyframes spin { 0% { transform: rotate(0deg); } 100% { transform: rotate(360deg); } }

Exercise 3: Notification Badge

Objective: Create a pulsing notification badge.

Add CSS to make the notification badge pulse to draw attention to it.

📬

Hints:
  • Use @keyframes to define a pulsing effect
  • Consider using scale transformation to make it pulse
  • You can also animate the color to enhance the effect
/* CSS */ .ex3-badge { position: absolute; top: -8px; right: -8px; width: 20px; height: 20px; background-color: #e74c3c; color: white; border-radius: 50%; font-size: 12px; display: flex; align-items: center; justify-content: center; animation: pulse 1.5s ease infinite; } @keyframes pulse { 0% { transform: scale(1); background-color: #e74c3c; } 50% { transform: scale(1.2); background-color: #ff7979; } 100% { transform: scale(1); background-color: #e74c3c; } }

Exercise 4: Simple Slideshow

Objective: Create a simple automatic slideshow that cycles through slides.

Add CSS animations to create an automatic slideshow that cycles through the four slides.

Hints:
  • Use @keyframes to define how slides should appear and disappear
  • Use animation-delay to stagger when each slide appears
  • Consider using opacity to fade slides in and out
/* CSS */ .ex4-slideshow { width: 300px; height: 200px; position: relative; overflow: hidden; } .ex4-slide { position: absolute; width: 100%; height: 100%; display: flex; align-items: center; justify-content: center; font-size: 24px; font-weight: bold; color: white; opacity: 0; animation: slideshow 10s infinite; } .ex4-slide:nth-child(1) { background-color: #3498db; animation-delay: 0s; } .ex4-slide:nth-child(2) { background-color: #e74c3c; animation-delay: 2.5s; } .ex4-slide:nth-child(3) { background-color: #2ecc71; animation-delay: 5s; } .ex4-slide:nth-child(4) { background-color: #9b59b6; animation-delay: 7.5s; } @keyframes slideshow { 0%, 20% { opacity: 0; } 25%, 45% { opacity: 1; } 50% { opacity: 0; } 100% { opacity: 0; } }

Exercise 5: Logo Animation

Objective: Create an animated logo effect.

Add CSS to create an engaging animation for the logo text below.

LOGO
Hints:
  • Get creative! Consider combining multiple transforms
  • Try using rotate(), scale(), or other transforms
  • Multiple keyframe stops can create more interesting animations
/* CSS */ .ex5-logo { font-size: 40px; font-weight: bold; color: #3498db; animation: logoAnimation 3s ease infinite; } @keyframes logoAnimation { 0% { transform: scale(1) rotate(0deg); } 25% { transform: scale(1.2) rotate(5deg); } 50% { transform: scale(1) rotate(0deg); } 75% { transform: scale(1.2) rotate(-5deg); } 100% { transform: scale(1) rotate(0deg); } }
