What I Learned (Responsive Design and Best Practices)

  1. how display: flex on a parent element lays out its children in a row or a column
  2. how a media query changes the layout only on bigger screens
  3. how link anchors let a menu jump to a specific post on the page

The biggest design practice I learned is to build for the phone first and then add a media query for bigger screens, because it is easier to add changes than to undo a desktop design. I also used a wrapper to keep the page from stretching too wide, dark text on light cards so it is easy to read, and a menu at the top so people can jump straight to the post they want. The viewport meta tag matters too, since without it a phone shows a shrunken desktop page. I wrote this layout with help from my course notes, and the Lab 5 video, and I tested it by resizing my browser.
